Document ingestion
Chunking
Embeddings
Vector database
Retrieval
Prompt augmentation
LLM answering
Evaluation
Optional improvements like reranking and memory


## Complete RAG Revision Project
Project Title

AI Research Assistant using RAG

Goal

Build a chatbot that answers questions from your own documents (PDFs, notes, research papers, docs, tutorials).

Example:

Upload ML notes
Ask:
“What is attention mechanism?”
“Explain vector embeddings”
“Summarize chapter 3”

The system retrieves relevant chunks and sends them to the LLM.
